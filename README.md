# SintaxEdu 🚀

Projeto Integrador: Aplicativo de estudo em ciências exatas com calculadora analítica passo a passo e síntese didática por IA.

## Estrutura do Repositório

```bash
SintaxEdu/
├── frontend/    # Aplicativo móvel (React Native / Expo SDK 57 / Expo Router)
└── backend/     # Servidor de API, banco de dados e integrações
```

---

## 📱 Frontend (Mobile)

Para executar o aplicativo mobile:

```bash
cd frontend
npm install
npx expo start
```

### Comandos de Verificação
```bash
cd frontend
npx tsc --noEmit   # Verificação de tipos TypeScript
npx expo lint      # Linting do código
```
